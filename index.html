One case study, all semester

Every week builds on the same Online Shop database: customers, products, suppliers, orders, order items and inventory. You start with the normalised design in Week 1 and keep adding to it, so by Week 12 you have seen every technique the assessment asks for working together in one system. Your own assessed project uses a business scenario you choose; the Online Shop is the worked example you learn from.

How to use these notes

In class

  • Press P (or the Present button) to show the lecture one section at a time, large enough to project. ← → move between sections; Esc exits.
  • SQL playgrounds run real SQLite in the browser. Every playground has its own copy of the database, so Reset always restores it.
  • ER diagrams switch between Crow’s Foot and Chen with one click, and all diagrams on the page switch together.

On your own

  • Work through the Lecture tab, then attempt the Seminar tasks before opening the model answers.
  • Download the Python scripts and databases from each week’s Resources tab and run them on your own computer.
  • Use / to search all notes. The theme button switches between automatic, light and dark.

Academic integrity and AI

From the assessment brief

Generative AI is not permitted for any part of this assessment, neither the report nor the code (database and GUI), including tools such as ChatGPT and GitHub Copilot. You may use AI and other tools for learning purposes only.

The examples on this site are general teaching examples built on the Online Shop. Use them to learn the techniques, then design and write your own system for your own scenario. Do not copy them into your submission.
